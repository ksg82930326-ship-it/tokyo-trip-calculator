# ✈ 도쿄 여행 경비 정산

친구들과 여행을 다녀온 뒤 경비를 쉽게 나눠 정산해 주는 웹 프로그램입니다.
엔화를 원화로 자동 환산하고, 카테고리별 지출을 보여 주며, 누가 누구에게 얼마를 보내면 되는지 계산해 줍니다.

🔗 **웹사이트:** https://ksg82930326-ship-it.github.io/tokyo-trip-calculator/

## 주요 기능

- **지출 추가**: 내용, 카테고리, 결제자, 금액, 통화(엔/원)를 입력하면 환율을 적용해 원화로 저장합니다.
- **지출 내역**: 입력한 지출 목록과 총액, 1인당 금액을 보여 주며 항목별로 삭제할 수 있습니다.
- **카테고리별 통계**: 항공, 숙소, 식비, 교통, 쇼핑, 기타별 합계와 비율을 막대 그래프로 보여 줍니다.
- **정산 결과**: 각자 낸 금액과 부담할 금액의 차이를 계산해 "누가 → 누구에게 얼마"를 알려 줍니다.
- **스마트폰 지원**: 화면 크기에 맞게 레이아웃이 조절됩니다.

## 사용 방법

1. 멤버 이름을 쉼표로 구분해 입력합니다. (2명 이상)
2. 엔화 지출이 있다면 환율(100엔당 원화)을 입력합니다.
3. 지출 내용, 카테고리, 결제자, 금액, 통화를 입력하고 **지출 추가**를 누릅니다.
4. 아래의 지출 내역, 카테고리별 통계, 정산 결과를 확인합니다.
5. 처음부터 다시 하려면 **전체 초기화**를 누릅니다.
